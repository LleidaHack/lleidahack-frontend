# LleidaHack Frontend

This repository now contains:

- `Landing` web for LleidaHack (`/lleidahack`)
- `Admin` web for management (`/admin`)

HackEPS landing code has been removed from runtime routes and project structure.

## Stack

- React (CRA)
- TailwindCSS
- PNPM

## Scripts

```bash
pnpm install
pnpm start
pnpm build
pnpm test
pnpm format
```
